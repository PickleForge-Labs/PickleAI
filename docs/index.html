🤖 What is PickleAI?

PickleAI is a local AI assistant designed to bring powerful AI tools directly to your desktop.

It combines AI chat, memory, automation, and computer tools into one personal assistant.

✨ Features

🧠 Memory

Keep conversations and information organized.

💻 PC Control

Interact with applications and automate tasks.

⚡ Local AI

Run AI models locally with Ollama.

🔒 Privacy Focused

Your AI experience stays under your control.

🌐 Smart Tools

Use online features when available.

🛠 Customizable

Built to grow with new features.

🚀 Why PickleAI?

Many AI assistants depend completely on cloud services. PickleAI focuses on giving users more control, flexibility, and personalization.

🛠 Technology

Python • PyWebView • SQLite • Ollama • Qwen2.5
