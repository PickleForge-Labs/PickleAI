🤖 About PickleAI

PickleAI is a local-first AI assistant that runs on your computer with memory, automation, PC tools, and smart features.

✨ Features

🧠 Memory

Remember information and keep conversations organized.

💻 PC Control

Open applications, control tools, and automate tasks.

⚡ Local AI

Powered by Ollama and local AI models.

🌐 Internet Capabilities

Use online features when an internet connection is available.

🛠 Technology

Python • PyWebView • SQLite • Ollama • Qwen2.5
